# Web Development Learning Summary

## 1. Why Websites Came Into Picture

Websites became a way to publish and access information/services over the Internet using a web browser.

Common uses:
- Sharing information
- Providing online services
- E-commerce
- Communication
- Web applications

---

## 2. Website vs Mobile App vs Desktop App

| Type | Runs On | Usually Installed? | Example |
|---|---|---|---|
| Website / Web App | Web browser | No | Google Docs |
| Mobile App | Android / iOS | Yes | Instagram app |
| Desktop App | Windows / macOS / Linux | Yes | VS Code |

A website is accessed through a browser. Mobile and desktop apps are installed applications designed for their respective platforms.

---

## 3. HTML

**HTML = HyperText Markup Language**

HTML is a **markup language**, not a programming language.

Purpose:
- Defines the structure of a webpage
- Tells the browser what content represents
- Creates headings, paragraphs, links, images, forms, sections, etc.

Basic relationship:

```text
HTML       -> Structure
CSS        -> Appearance / Layout
JavaScript -> Behaviour / Interactivity
```

---

## 4. HTML Tags and Elements

A typical HTML element:

```html
<h1>Welcome</h1>
```

- `<h1>` = opening tag
- `Welcome` = content
- `</h1>` = closing tag

Tags describe the purpose/structure of content.

---

## 5. Standard HTML Document Structure

Basic structure:

```html
<!DOCTYPE html>
<html lang="en">

<head>
    ...
</head>

<body>
    ...
</body>

</html>
```

### `<!DOCTYPE html>`

Declares that the document uses modern HTML5.

### `<html>`

Root element of the HTML document. Everything normally goes inside it.

### `<head>`

Contains information/resources about the page rather than the main visible content.

### `<body>`

Contains the visible/interactable content of the webpage.

---

## 6. `<meta>`

Provides metadata/configuration for the webpage.

Example:

```html
<meta charset="UTF-8">
```

Specifies character encoding.

Responsive-page example:

```html
<meta name="viewport"
      content="width=device-width, initial-scale=1.0">
```

Helps the page display correctly on different screen sizes.

---

## 7. CDN Links

**CDN = Content Delivery Network**

A CDN can provide resources such as:
- CSS libraries
- JavaScript libraries
- Fonts
- Other static files

A page can load a library from a CDN instead of hosting the library itself.

Example concept:

```html
<link rel="stylesheet" href="...">
```

# Semantic HTML Tags We Learned

## 8. `<header>`

Represents introductory/header content for a page or section.

Common contents:
- Website logo/name
- Main heading
- Navigation
- Search
- User/profile controls

Example:

```html
<header>
    <h1>YouTube</h1>
    <nav>...</nav>
</header>
```

A header does **not** automatically stay fixed while scrolling. CSS controls that behavior.

---

## 9. `<nav>`

Represents a group of important navigation links.

Example:

```html
<nav>
    <a href="#home">Home</a>
    <a href="#about">About</a>
    <a href="#contact">Contact</a>
</nav>
```

`<nav>` can be used inside a `<header>` or `<footer>`.

It does not automatically create a visual navigation bar. CSS controls its appearance.

---

## 10. `<a>`

Creates a hyperlink.

Example:

```html
<a href="#explore">Explore</a>
```

`href="#explore"` means the browser looks for an element with:

```html
id="explore"
```

Important distinction:

```html
<div class="explore">
```

does **not** match:

```html
<a href="#explore">
```

For that link to jump to the element, use:

```html
<div id="explore">
```

---

## 11. `<main>`

Contains the primary content of the webpage.

Typical structure:

```text
<body>
├── <header>
├── <main>
└── <footer>
```

A page normally has one main `<main>` element.

---

## 12. `<section>`

Represents a meaningful section of content.

Example:

```html
<section id="explore">
    <h2>Explore</h2>
    <p>Discover new content.</p>
</section>
```

Use `<section>` when the content forms a meaningful section, rather than using `<div>` for everything.

---

## 13. `<div>`

A generic container.

It is useful for:
- Grouping elements
- Applying CSS
- Creating layout containers

Example:

```html
<div class="thumbnail-container">
    ...
</div>
```

A `<div>` does not describe what the content means. It mainly provides a container.

---

## 14. `<h1>` and `<h2>`

### `<h1>`

Main/primary heading of the page.

```html
<h1>YouTube</h1>
```

### `<h2>`

Subheading/second-level heading.

```html
<h2>Trending</h2>
```

Example hierarchy:

```text
<h1> YouTube
    ├── <h2> Explore
    ├── <h2> Trending
    ├── <h2> Comedy
    └── <h2> Watched
```

---

## 15. `<p>`

Represents a paragraph of text.

```html
<p>Discover new content you may be interested in.</p>
```

---

## 16. `<img>`

Displays an image.

Example:

```html
<img src="images/Thumbnail1.png"
     alt="Thumbnail 1">
```

### `src`

Specifies the image location.

### `alt`

Provides alternative text describing the image.

Useful for accessibility and when an image cannot be displayed.

---

## 17. `<ul>` and `<li>`

### `<ul>`

Unordered/bulleted list.

### `<li>`

Individual list item.

Example:

```html
<ul>
    <li>Trending Video #1</li>
    <li>Trending Video #2</li>
    <li>Trending Video #3</li>
</ul>
```

---

## 18. `<br>`

Creates a line break.

Example:

```html
Hello<br>
World
```

However, avoid using `<br>` just to create visual spacing between sections.

Prefer CSS:

```css
.thumbnail-container {
    margin-bottom: 40px;
}
```

---

## 19. `<footer>`

Represents footer information for a page or section.

Common contents:
- Copyright
- Privacy Policy
- Terms
- Contact links
- Additional navigation

Example:

```html
<footer>
    <p>&copy; 2026 My Website.</p>

    <nav>
        <a href="privacy.html">Privacy</a>
        <a href="terms.html">Terms</a>
    </nav>
</footer>
```

A footer normally comes after the main content.

# CSS Concepts We Learned

## 20. CSS Classes

HTML:

```html
<div class="thumbnail-container">
```

CSS:

```css
.thumbnail-container {
    display: flex;
    gap: 20px;
}
```

A class can be reused on multiple elements.

Use classes when multiple elements need the same styling.

---

## 21. `display: flex`

```css
.thumbnail-container {
    display: flex;
}
```

Turns the container into a Flexbox container.

Its children are arranged using Flexbox.

Example:

```text
[Thumbnail 1]  [Thumbnail 2]  [Thumbnail 3]
```

---

## 22. `gap`

```css
gap: 20px;
```

Creates space between Flexbox/Grid items.

---

## 23. CSS Descendant Selector

```css
.thumbnail-container img {
    ...
}
```

Means:

> Select `<img>` elements that are inside `.thumbnail-container`.

This is more specific than styling every image with:

```css
img {
    ...
}
```

---

## 24. Image Styling

Example:

```css
.thumbnail-container img {
    width: 200px;
    height: 120px;
    object-fit: cover;
    border: 2px solid black;
}
```

### `width`

Controls width.

### `height`

Controls height.

### `object-fit: cover`

Makes an image fill the specified dimensions while maintaining its aspect ratio, potentially cropping part of the image.

### `border`

```css
border: 2px solid black;
```

Means:
- `2px` = thickness
- `solid` = border style
- `black` = color

---

## 25. `margin` vs `padding`

### `padding`

Space **inside** an element's box.

```css
padding: 10px;
```

### `margin`

Space **outside** an element's box.

```css
margin: 10px;
```

Simple mental model:

```text
       margin
    ┌───────────────┐
    │    border     │
    │  ┌─────────┐  │
    │  │ padding │  │
    │  │ content │  │
    │  └─────────┘  │
    └───────────────┘
```

---

## 26. `display: block`

```css
img {
    display: block;
}
```

Makes an element behave as a block-level element.

Block elements generally start on a new line and can take width/height.

---

## 27. `margin: 0 auto`

```css
margin: 0 auto;
```

Commonly used to horizontally center a block element when it has an appropriate width.

---

## 28. `box-sizing`

When width/height, padding, and borders are combined, the default CSS box model can make the final element larger than expected.

Using:

```css
box-sizing: border-box;
```

makes the declared width/height include padding and border.

# Navigation and Scrolling

## 29. Fixed Header

A header does not automatically stay visible during scrolling.

CSS can make it fixed:

```css
header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}
```

`position: fixed` attaches the element to the browser viewport.

Because a fixed element is removed from normal document flow, the page content may need top padding.

---

## 30. Sticky Header

Another option:

```css
header {
    position: sticky;
    top: 0;
}
```

A sticky element behaves normally until it reaches the specified position, then sticks there while scrolling.

---

## 31. Fixed Footer

A footer can also be fixed:

```css
footer {
    position: fixed;
    bottom: 0;
    width: 100%;
}
```

But a normal footer usually appears after the page's main content and scrolls normally.

---

# `class` vs `id`

## 32. `class`

Used mainly for grouping/styling multiple elements.

```html
<div class="explore">
```

CSS:

```css
.explore {
    ...
}
```

A class can be reused.

---

## 33. `id`

Used to uniquely identify an element.

```html
<section id="explore">
```

It can be targeted by a link:

```html
<a href="#explore">Explore</a>
```

Mental model:

```text
class -> reusable group/style
id    -> unique identifier/target
```

# HTML Entities

## 34. `&copy;`

```html

```

Displays:

```text
©
```

Example:

```html
<p>&copy; 2026 My Website.</p>
```


# Current YouTube Page Structure

The concepts we've practiced can form a structure like:

```text
<body>
│
├── <header>
│   ├── <h1>
│   └── <nav>
│       └── <a>
│
├── <main>
│   ├── <div class="thumbnail-container">
│   │   └── <a>
│   │       └── <img>
│   │
│   ├── <section id="explore">
│   │   ├── <h2>
│   │   └── <p>
│   │
│   ├── <section id="trending">
│   │   ├── <h2>
│   │   ├── <p>
│   │   └── <ul>
│   │       └── <li>
│   │
│   └── Other sections
│
└── <footer>
    ├── <p>
    └── <nav>
        └── <a>
```

## Key corrections to remember

1. Use `<main>` for the primary page content.
2. Use `<section>` for meaningful content sections.
3. Use `<div>` for generic grouping/layout.
4. Use `<nav>` for navigation links.
5. `<nav>` can be inside `<header>` or `<footer>`.
6. `<header>` and `<footer>` do not automatically stay fixed.
7. Use CSS `position: fixed` or `position: sticky` for scrolling behavior.
8. `href="#something"` targets `id="something"`, not `class="something"`.
9. Use CSS spacing instead of `<br><br>` for layout.
10. Use classes for reusable styling and IDs for unique targets.
11. HTML provides structure/meaning; CSS controls appearance/layout.
